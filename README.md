🇬🇧 English | How to Add It to Your iPhone

If you’re using an iPhone, adding this Persian calendar is super easy. You don’t need to manually add the dates or events one by one.

📱 iPhone Setup

First, copy the calendar subscription link:

https://github.com/DaAnxiety/icalender_1405_1406/raw/refs/heads/main/Persian_Calendar_1405_1406_Complete_Monthly_22_FINAL.ics

Then go to:

Settings → Apps → Calendar → Calendar Accounts → Add Account → Other → Add Subscribed Calendar

Paste the copied link into the Server field.

Then tap:

Next → Save → Done

That’s it! 🎉

Now open the Calendar app on your iPhone.

The Persian calendar and its events should appear in your calendars.

🔄 Calendar Updates

This calendar is added as a Subscribed Calendar, so when the .ics file is updated on GitHub, your iPhone can fetch the updated calendar automatically.

You don’t need to add the calendar again every time the repository is updated.

💡 If new events don’t appear immediately after an update, give Apple Calendar some time to refresh the subscription.
